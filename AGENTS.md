## Icon work — canonical workspace playbook

Read [ICON_RULES.md](../core/ICON_RULES.md) before icon work in this workspace. It defines Goal, Rules, Design, implementation workflow, Verification, Tests and completion criteria across the source repositories and local review app. Keep current numeric specifications there; older dated construction values in supporting documents are history when superseded by the playbook. Also follow this repository's contribution instructions.

## Morph work

Before implementing or revising any morph, read the canonical
[shared agent playbook](../core/MORPH.md) and this repository's
[CONTRIBUTING.md](CONTRIBUTING.md). The playbook defines Goal, Design, workflow,
Verification, Tests and delivery across core, Svelte and the standalone local Lab.

A named morph request means implement through to a working Lab preview. The owner
explicitly permits questions whenever unsure about a material decision; the design
brief is not a mandatory approval checkpoint. Preserve unrelated user work.

If the sibling core checkout is unavailable, read the
[core reference](https://github.com/squircle-icons/core/blob/main/MORPH.md) at the
relevant source revision. Link to the playbook rather than maintaining another copy.
